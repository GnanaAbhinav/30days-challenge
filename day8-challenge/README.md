Campus security has divided a high-traffic area into an N × N grid. Each cell stores a risk score from a sensor: 0 means no risk and 100 means the highest risk. You must build a C program called GRIDWATCH that traverses the grid in different ways to identify risky zones and recommend a response. This is not just a maximum-value problem: your solution must correctly analyse rows, columns, diagonals, boundaries, and neighbouring cells.
Start.
Read N from 3 to 6.
Read N*N integer risk scores from 0 to 100.
Read warning threshold T from 1 to 100.
Use loops such as while,do-while,and nested loops.
Use conditional statements such as IF,ELSE-IF,and ELSE to check whether the condition is true or not.
Print rows with highest total.
Print columns with highest total.
Print the highest risk score.
Print occurs at positions from row and column numbers starting from 1.
Print total cells>=T.
Print main diagonal sum and secondary diagonal sum.
Print boundary total sum.
Print hotspot at point with score.
Print decision.
Stop.
